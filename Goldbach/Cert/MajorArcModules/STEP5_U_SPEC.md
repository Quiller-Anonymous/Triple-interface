# Step 5 (ε₂-large) — “U-spec” for the TT*/Toeplitz certificate

This file is the **handoff/spec sheet** for the ε₂-large (large-β) TT*/Toeplitz certificate work.
It records what must be proven (deterministically in Lean) vs what remains “analytic”, and—most
importantly—what *must not* be done if we want to beat the `+Q0^2` barrier.

Status: the deterministic algebra/finite-support layer is already implemented (see below).  The
remaining work is to choose (and then formalize) a **dispersion step** that suppresses cross-terms
in `q,q'` *before* taking absolute values.

## Window reduction (deterministic; check only the top endpoint)

For the Toeplitz scaffold, the only `N`-dependence on the *bound side* comes from:

- `coeffMass(X,N) := ∑_{n∈s N} ‖aTerm X n‖²` (the split range grows with `N`), and
- `kernelMass(X,Δ,N) := ∑_{t∈Icc(-N)N} ‖Ŵ_X(t)‖²` (the frequency band grows with `N`).

Both are monotone in `N`, so for any `N ∈ EvenIn(X,H)` we have the uniform replacements

`coeffMass(X,N) ≤ coeffMass(X, X+H)`,
`kernelMass(X,Δ,N) ≤ kernelMass(X,Δ, X+H)`.

Lean location:
`Goldbach/Cert/MajorArcModules/Q0MajorTailTTStarToeplitzScaffold.lean`
(`coeffMass_mono_N`, `kernelMass_mono_N`) plus
`Goldbach/Cert/MajorArcModules/Q0MajorWindowBounds.lean`
(`le_X_add_H_of_mem_EvenIn`).

Practical consequence for certificates/experiments: whenever a bound is monotone in `N`,
**it is enough to test / certify the endpoint `N = X + H`** (or at worst the two endpoints).

## The exact “W-hat” structure (hard arcs, disjointness regime)

For the *hard* major arcs weight
`W_X(α) = 1_{majorArcSetQ0(X,Δ)}(α)` on `α ∈ [0,1]`,
in the disjointness regime (`SepQ0 X Δ`, in particular for `X ≥ X0` and `Δ=1`),
the α-Fourier coefficient is (for `t ≠ 0`):

`Ŵ_X(t) = (1/(π t)) * ∑_{q≤Q0} c_q(t) * sin(2π t/(qX))`,

where `c_q(t)` is the Ramanujan sum over reduced residues mod `q`.

This identity is the reason TT*/Toeplitz is plausible: `Ŵ_X(t)` is tiny for `t ≠ 0` and the “q-sum”
has strong cancellation.

## What we must NOT do (policy; numerically fatal)

These two moves reintroduce the `+Q0^2` barrier and will not lead to a `U ≤ M2^2` proof.

1) Do **not** replace `c_q(t)` by `|c_q(t)|` *before* squaring/averaging.
2) Do **not** take an ℓ∞ / `sup_k` bound on the Toeplitz progression
   `∑_n |Ŵ_X(2n+k-N)|^2` as a surrogate for the TT* sum.

Coarse is allowed **only after** the dispersion step has produced a positive expression in which
cross-terms are already eliminated/suppressed.

## What we DO need (single missing analytic payload)

We need one “dispersion” lemma that is applied **inside**

`∑_k |F_k|^2 = ∑_k ∑_{n,n'} a_n a_{n+k} a_{n'} a_{n'+k} Ŵ_X(t) * conj(Ŵ_X(t'))`

with `t = 2n + k - N`, `t' = 2n' + k - N`, and which:

- kills/suppresses the cross terms `q ≠ q'` arising from substituting
  `Ŵ_X(t) = (1/(πt)) ∑_{q≤Q0} c_q(t) sin(2πt/(qX))`,
- while keeping the `q`-sum intact until after the averaging/squaring stage.

After that step, the remaining bounds can be crude (divisor sums, `|sin|≤1`, `Λ(n)≤log N`, etc.).

## Next tightening candidate: linearized Ramanujan-q cancellation (deterministic, fast)

In the TT*/Toeplitz band (`|t| ≲ 2N0`), for all `q ≥ 13` we are in the small-angle regime:

`|2π t/(qX0)| ≤ 2π*(2N0)/(13*X0) < 1`.

So for `q ≥ 13` we can write

`sin(2π t/(qX)) = (2π t/(qX)) + err_q(t)` with `|err_q(t)| ≤ (2π t/(qX))^3 / 6`.

This suggests a **structure-preserving** decomposition of the hard-arc Fourier coefficient:

- split `Ŵ_X(t)` into the exact small-`q` part (`q ≤ 12`) and the small-angle part (`q ≥ 13`),
- replace the `q ≥ 13` part by its linear term (which keeps the full Ramanujan cancellation),
- bound the remainder `∑_{q≥13} c_q(t) * err_q(t)` crudely (it is tiny because of the `q^{-3}`).

The key point: the linearized `q ≥ 13` contribution has an explicit divisor-convolution form.
Using `c_q(t) = ∑_{d|gcd(q,t)} μ(q/d) * d`, one gets the exact identity

`∑_{q≤Q0} c_q(t)/q = ∑_{d|t, d≤Q0} ( ∑_{m≤Q0/d} μ(m)/m )`.

So the “linear main term” is:

`W_lin(t) := (2/X) * ∑_{q≤Q0} c_q(t)/q`,

and **its entire ℓ²-mass over `t≤Tmax` can be computed deterministically in `O(Tmax log Q0)`**
via the divisor-add method (see `scripts/experiments/exp_q0_w_hat_linear_main_l2.py`).

This is the current best candidate for the *first* dispersion-tightening step because:

- it keeps the `q`-sum cancellation intact (no `|c_q(t)|`), and
- it produces a finite, explicit expression that is generator-friendly (only involves `μ(m)/m` partial sums).

### Immediate “passes-budget” experimental scaffold: split `q≤12` vs `q≥13`

For `t` in the TT*/Toeplitz bandwidth (`|t|≤2N0`), `q≥13` is always in the small-angle regime, so:

`sin(2π t/(qX)) = 2π t/(qX) + err_q(t)` with `|err_q(t)| ≤ (2π t/(qX))^3 / 6`.

This motivates the *hybrid* decomposition (still to be made rigorous):

- define the small-`q` piece exactly:
  `W_small(t) := (1/(π t)) * ∑_{1≤q≤12} c_q(t) * sin(2π t/(qX))`,
- define the large-`q` linear term using the divisor-convolution identity:
  `W_large_lin(t) := (2/X) * ∑_{13≤q≤Q0} c_q(t)/q`,
- then `W_hat(t) = W_small(t) + W_large_lin(t) + W_err(t)` where `W_err(t)` is the `q≥13` remainder.

The success criterion for tightening is to bound the ℓ² mass of `W_err` on the band, so that we can
replace `W_hat` by `W_small + W_large_lin` in the TT*/Toeplitz bound without blowing the budget.

### Deterministic bound for the `q≥13` Taylor remainder (explicit, uniform)

For `q ≥ 13` and `|t| ≤ N` with `N ∈ EvenIn X H`, we have the uniform small-angle bound

`|2π t/(qX)| ≤ 2π*(N/X)/q ≤ (2π*1.01)/13 < 1`.

So we may use the standard inequality (conventional calculus; one-line proof from the Taylor
remainder for `sin`):

`|sin y - y| ≤ |y|^3/6` for `|y| ≤ 1`.

Define the remainder kernel (exactly):

`W_err(t) := (1/(π t)) * ∑_{q=13..Q0} c_q(t) * (sin(2π t/(qX)) - (2π t/(qX)))`  (for `t ≠ 0`).

Then for `t ≠ 0`, using `|c_q(t)| ≤ gcd(q,t) ≤ q` and the Taylor bound:

`|W_err(t)| ≤ (1/(π|t|)) * ∑_{q≥13} q * (2π|t|/(qX))^3 / 6
           = (4π^2|t|^2)/(3X^3) * ∑_{q≥13} 1/q^2
           ≤ (π^2/9) * |t|^2 / X^3`,

since `∑_{q≥13} 1/q^2 ≤ ∫_{12}^∞ x^{-2} dx = 1/12`.

Consequently, for the even-frequency band needed by the Toeplitz progression bound,
letting `N0 := X0+H` and evaluating at the worst case `X=X0`:

`∑_{1≤t≤N0, t even} |W_err(t)|^2 ≤ (π^4/81) * (1/X0^6) * ∑_{1≤t≤N0, t even} t^4
                               ≈ 1.264e-07`,

so (with the standard “two-to-one” progression counting factor) the corresponding progression cap is

`BW_err := 2 * ∑_{t even≤N0} |W_err(t)|^2  ≲ 2.528e-07`.

This is ~50× smaller than `BW_mix ≈ 1.285e-05`, hence (empirically and in crude deterministic
estimates) the remainder cannot dominate the TT*/Toeplitz budget.

## A First Frozen Scaffold Inequality for `U` (explicit, generator-computable)

This section answers: “what is the explicit `U = Expr(Q0,X0,H,…)` inequality we can already
certify, **today**, without dispersion?”

It is intentionally **too coarse** to meet the pinned budget `M2=50_000`; it exists to:

- freeze a deterministic end-to-end reduction from the TT* sum to a finite explicit arithmetic
  expression, and
- provide the first experiment target for the generator (`scripts/gen_q0_major_tail_ttstar_cert.py`)
  so we can start tightening step-by-step.

### Freeze: α-weight and the `t=0` mode

- **α-weight is hard and unbalanced.** In the Lean definition,
  `innerMajorQ0 X N Δ β = ∫_{α∈[0,1]} 1_{MA_{Q0}(X,Δ)}(α) · innerIntegrand(X,N,β,α) dα`.
  So there is no choice to “switch” weights inside the target statement. Any use of `wTextbook`
  (smooth weight) is only allowed as an *upper bound* step in a proof.

- **`t=0` is handled separately.** The exact Ramanujan–sinc formula is only for `t ≠ 0`.
  For `t=0` and disjoint arcs, we have the exact identity
  `Ŵ_X(0) = (2Δ/X) * ∑_{q≤Q0} φ(q)/q` (a single “mass” constant).
  For per-`q` bookkeeping (after summing over `a`), the exact per-`q` contribution is
  `Ŵ_{X,q}(0) = φ(q) · (2Δ)/(qX)`; boundary truncation can only *decrease* the integral on `[0,1]`.

### Freeze: worst-case over the `N`-window (for uniformity in `N ∈ EvenIn X H`)

All TT*/Toeplitz bounds in this step are required uniformly for `N ∈ EvenIn X H`, i.e.
`N` even and `X ≤ N ≤ X+H`.

Deterministic simplifications we will use everywhere:

- The Toeplitz “time” index is `t = 2n + k - N` with `n ∈ [2, N-2-k]`, hence
  `|t| ≤ N` and, in particular, the relevant band is `1 ≤ |t| ≤ N`.
- Since `N ≤ X+H`, it is always safe (and certificate-friendly) to replace `N` by `X+H`.
- Since `X ≥ X0`, we always have `N/X ≤ (X+H)/X ≤ 1 + H/X0 = 1.01`.
  This is the key “uniformity knob” that makes small-angle remainders and other monotone terms
  independent of the specific `N ∈ [X,X+H]`.

### Deterministic “Toeplitz progression” counting bound (removes dependence on `k` and interior `N`)

In the Toeplitz coefficient `F_k`, the α-frequency argument is

`t(n,k,N) := 2n + k - N` with `n ∈ [2, N-2-k]`.

Two structural facts we exploit repeatedly:

1) **Parity.** If `N` is even, then `t(n,k,N) ≡ k (mod 2)` for all `n`. So the relevant band-sums
   split cleanly into the even-`t` and odd-`t` classes, depending only on the parity of `k`.

2) **Two-to-one bound.** As `n` varies, `|t(n,k,N)|` changes by steps of `2`, with a single turning
   point. Therefore each admissible `t` value of the correct parity occurs for at most **two**
   different `n` values. Consequently, for any nonnegative function `g : ℕ → ℝ` we have the
   deterministic inequality

   `∑_{n=2..N-2-k} g(|t(n,k,N)|) ≤ 2 * ∑_{1≤t≤N, t≡k (mod 2)} g(t) + g(0)`,

   where the final `g(0)` term accounts for the (possible) single index with `t(n,k,N)=0`.

For the TT*/Toeplitz upper bound, we apply this with `g(t) = |Ŵ_X(t)|^2` (or `|W_mix(t)|^2` in the
hybrid decomposition), so the only remaining “worst case over the window” is to replace `N` by
`X+H` and (for constant-mode bookkeeping) bound the `t=0` contribution separately.

These conventions are frozen for the first scaffold.

### Notation (matches the Lean algebra layer)

Fix `X ≥ X0`, `N ∈ EvenIn(X,H)`, `Δ=Δ_canon=1`. Let `s(N) = {n ∈ ℕ : 2 ≤ n ≤ N-2}`.

The β-Fourier coefficient at frequency `k` is (Toeplitz form, already proved in Lean):

`F_k(X,N) = ∑_{n ∈ s(N) ∩ (s(N) - k)} aTerm(X,n) aTerm(X,n+k) · Ŵ_X(2n+k-N)`,

where

`Ŵ_X(t) := ∫_{α∈[0,1]} 1_{MA_{Q0}(X,Δ)}(α) · e(tα) dα`  (α-Fourier coefficient of the hard major-arc weight)

and `e(t)=exp(2π i t)`.

The TT*/Parseval sum we are certifying is (finite support `kSupport(N)` already proved in Lean):

`TT(X,N) := ∑_{k ∈ kSupport(N)} |F_k(X,N)|^2`.

### Explicit disjoint-arcs formula for `Ŵ_X(t)` (no inequality yet)

Under the separation hypothesis `SepQ0(X,Δ)` (in particular `X ≥ X0` and `Δ=1` imply it),
the arcs are pairwise disjoint and for `t ≠ 0` one has the exact identity

`Ŵ_X(t) = (1/(π t)) · ∑_{q≤Q0} c_q(t) · sin(2π tΔ/(qX))`,

where `c_q(t)` is the Ramanujan sum over reduced residues mod `q`.

This is the point at which the **q-sum structure is exposed** and must be preserved until after
we square/average (the policy above).

### The “scaffold” upper bound (blockwise C–S in `q`, then crude bounds)

Define the per-`q` contribution to `Ŵ_X(t)` by

`Ŵ_{X,q}(t) := (1/(π t)) · c_q(t) · sin(2π tΔ/(qX))` for `t ≠ 0`, and
`Ŵ_{X,q}(0) := (2Δ)/(qX) · c_q(0) = φ(q) · (2Δ)/(qX)` (disjoint arcs; exact for the hard-arc weight).

Then `Ŵ_X(t) = ∑_{q≤Q0} Ŵ_{X,q}(t)` for all `t ∈ ℤ`.

Define the per-`q` Toeplitz coefficient by

`F_{k,q}(X,N) := ∑_{n} aTerm(X,n) aTerm(X,n+k) · Ŵ_{X,q}(2n+k-N)`.

Then `F_k = ∑_{q≤Q0} F_{k,q}`.

Now choose a fixed finite “q-block partition” of `{1,…,Q0}` (we use the dyadic blocks already
implemented in `Q0MajorTailTTStarBlocks.lean`). Let `B = #blocks` and `b_j = #q in block j`.

Blockwise Cauchy–Schwarz (deterministic) gives:

`TT(X,N) = ∑_k |∑_j ∑_{q∈block(j)} F_{k,q}|^2 ≤ B · ∑_j ∑_k |∑_{q∈block(j)} F_{k,q}|^2`.

Within each block, C–S in `q` gives:

`∑_k |∑_{q∈block(j)} F_{k,q}|^2 ≤ b_j · ∑_{q∈block(j)} ∑_k |F_{k,q}|^2`.

So the TT* sum satisfies the explicit reduction:

`TT(X,N) ≤ B · ∑_j b_j · ∑_{q∈block(j)} E_q(X,N)`

where

`E_q(X,N) := ∑_{k ∈ kSupport(N)} |F_{k,q}(X,N)|^2`.

At this point we can be crude **inside** `E_q` (this is the “after squaring/averaging” stage).
For a fully explicit generator-friendly expression, one admissible (very conservative) upper bound is:

- replace `|c_q(t)|` by `gcd(q,t)`,
- replace `|sin(y)|` by `min(|y|,1)`,
- use the deterministic `Λ(n) ≤ log(N+1)` and `|aTerm(X,n)| = |Λ(n)|`,
- replace `X` by `X0` and `N` by `N0 := X0+H` (monotone worst-case).

Concretely, define for integers `t` (with `t=0` treated separately)

`S_q(t) := gcd(q,t) · min( 2/(qX0), 1/(π|t|) )`.

Then for all `X≥X0`, `N∈EvenIn(X,H)`, and all `k`,

`|F_{k,q}(X,N)| ≤ (log(N0+1))^2 · ∑_{n∈s(N0)} S_q(2n+k-N0)`,

hence

`E_q(X,N) ≤ (#kSupport(N0)) · (log(N0+1))^4 · (∑_{n∈s(N0)} S_q(2n+k-N0))^2`,

and therefore the fully explicit (finite, arithmetic-only) **scaffold bound**:

`TT(X,N) ≤ U_scaffold(Q0,X0,H)` where

`U_scaffold(Q0,X0,H) :=
  B(Q0) · ∑_{j< B(Q0)} b_j(Q0) · ∑_{q∈block(j)} U_q(Q0,X0,H)`

and

`U_q(Q0,X0,H) :=
  (#kSupport(N0)) · (log(N0+1))^4 · max_{k∈kSupport(N0)} (∑_{n∈s(N0)} S_q(2n+k-N0))^2`.

Everything in `U_scaffold` is now a **finite, explicit computation**:
finite sums over `q≤Q0`, `k∈[-N0,N0]`, and `n∈[2,N0-2]`, plus gcd and rational functions.

This is the first place where the generator can start computing real numbers and reporting
“passes/fails” relative to `M2^2 = 2.5e9`. The next tightening steps replace the max/sup and
crude `gcd` bound by increasingly structured “dispersion” inputs.

### Make it computable: remove `max_k` (k-independent envelope)

The previous `U_q` still contains `max_{k∈kSupport(N0)}`. To make the first certificate generator
possible, we replace it by a k-independent envelope.

Let `N0 := X0 + H` and define the full `t`-range needed by the Toeplitz map
`t(n,k) = 2n + k - N` on `n ∈ s(N0)` and `k ∈ kSupport(N0)`:

- `|t(n,k)| ≤ Tt` with `Tt := 2*N0`.

Fix a purely rational constant `Cπinv := 1/3` (since `1/π ≤ 1/3`), and define for `t ≠ 0`

`B_q(t) := gcd(q,|t|) · min( 2/(qX0), Cπinv/|t| )`,

and for `t=0`

`B_q(0) := φ(q) · 2/(qX0)`.

Then for all `X ≥ X0` and `t ∈ ℤ`,

`|Ŵ_{X,q}(t)| ≤ B_q(t)` (after replacing `X` by `X0` and using the trivial bounds on `sin`).

Define the k-independent `t`-envelope:

`A_q := ∑_{t∈Icc(-Tt,Tt)} B_q(t) = B_q(0) + 2 * ∑_{t=1}^{Tt} gcd(q,t) · min( 2/(qX0), Cπinv/t )`.

Then for every `k`, the sampled progression sum satisfies:

`∑_{n∈s(N0)} |Ŵ_{X,q}(2n+k-N0)| ≤ A_q`.

Now use `|aTerm(X,n)| = |Λ(n)| ≤ log(N0+1)` and freeze an explicit rational upper bound
`Lmax := 14` for `log(N0+1)` (since `N0+1 = 1_010_001`).

This yields the fully explicit bound, uniform in `X≥X0`, `N∈EvenIn(X,H)`:

`E_q(X,N) := ∑_{k∈kSupport(N)} |F_{k,q}(X,N)|^2
   ≤ (#kSupport(N0)) · (Lmax^4) · (A_q^2)`.

Plugging this into the blockwise C–S reduction gives the **computable scaffold**

`TT(X,N) ≤ U_expr(Q0,X0,H)` where

`U_expr(Q0,X0,H) :=
   B(Q0) · (#kSupport(N0)) · (Lmax^4) · ∑_{j< B(Q0)} b_j(Q0) · ∑_{q∈block(j)} A_q^2`.

All terms are now finite integer/rational sums with gcd/totient and a single harmonic-like split
(only needed for `q ≤ 12`, since `qX0/6 ≥ Tt` makes the `min` equal to `2/(qX0)` everywhere).
