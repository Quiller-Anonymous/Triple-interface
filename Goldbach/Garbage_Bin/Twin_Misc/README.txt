# README_build_falsifiers.md## PurposeThis file explains how to reconstruct the full **Twin Primes falsifier suite** (`twin_primes_falsifiers_full.zip`) from a single build script. The suite contains all checks referenced in the manuscript (TT/Torus model): K1-exactness, two-leg annihilation (GCD kill), AO Gram–Gershgorin, SSU (short-shift uniformizer), Type–I ledger, bank-weight FFT (PSB), near-collision strip count (model), IBP uniform derivatives + Mellin factor, and the fix-up sweepers for Type–I and SSU.---## Prerequisites- Python 3.9 or newer- Ability to create a virtual environment and install `numpy`, `scipy`, `mpmath`, `matplotlib`No internet access is required after you have the build script.---## Build the bundle1. Save the build script as a file named:build_falsifiers.py2. Run the builder:```bashpython build_falsifiers.pyThis createstwin_primes_falsifiers_full.zip## Use the bundle1. Run all baseline gates:python ../run_all.py3.
